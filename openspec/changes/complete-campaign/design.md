# Design

Use the hall, calendar clock and fixed-step input protocol already exercised by the rehearsal. A door defines authored spaces, a small tool set, objective transitions, a safe checkpoint and a unique keepsake. Checkpoints and saves reference stable door and objective IDs. A host validates party actions, replicates state and grants extraction once.

The vertical-slice gate pairs the cinema with an economy mission. Produce two measured 20-minute missions before forecasting the rest. Build gameplay systems once, then vary how the spaces, enemies, art and objectives use them. The sequence and complete production criteria are in the [campaign design](../../../design/lantern-hall.md) and [implementation design](../../../design/engineering.md).
